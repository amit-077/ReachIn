# 🚀 ReachIn

**ReachIn** is a Chrome extension that helps you write **personalized LinkedIn connection messages** using AI.
It analyzes a profile’s content and generates concise, context-aware outreach so you can stand out beyond generic requests.

---

## ✨ Features

* 🔍 Extracts profile insights (About section, recent posts)
* 🤖 Generates personalized connection messages using AI
* ✍️ Keeps messages concise, relevant, and human-like
* ⚡ Simple setup with your own OpenAI API key

---

## 📦 Installation Guide

> ⚠️ ReachIn is not yet on the Chrome Web Store. For now, you need to install it locally.

## How to install (video)
https://github.com/user-attachments/assets/2130ef72-6665-46a3-803c-3bbeb6d7a2fc



### Step 1: Install ReachIn Locally

ReachIn is **100% safe and transparent** — the full codebase is available for review 😎

1. **Download the project**

   * Either download the ZIP file or run:

     ```bash
     git clone <your-repo-url>
     ```

2. **Open Chrome Extensions**

   * Go to:

     ```
     chrome://extensions/
     ```

3. **Enable Developer Mode**

   * Toggle **"Developer mode"** (top right corner)

4. **Load the Extension**

   * If you downloaded ZIP → unzip it first
   * Click **"Load unpacked"**
   * Select the **ReachIn folder**

5. **Pin the Extension**

   * Click on Extensions icon → find ReachIn
   * Click **Pin to toolbar**

✅ Done! ReachIn is now installed.

---

## ⚙️ Setup Guide

### Step 2: Configure ReachIn

1. Open **LinkedIn**
2. Click on the **ReachIn extension icon**
3. Fill in:

   * 🧾 **Your Summary**
     (Write about yourself — your background, interests, goals)
   * 🔑 **OpenAI API Key**
4. Click **Save**

✅ You're all set!

## 🧠 How to Use

1. Go to any LinkedIn profile
2. Open ReachIn
3. Generate a personalized connection message

ReachIn will:

* Analyze the profile
* Find meaningful context
* Create a clean, tailored message for you

## 💡 Tips for Best Results
